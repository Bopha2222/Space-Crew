# Space-Crew
Group project for DSA year 2. Game play "Space crew".
This is the Github reposity for our project.
Each member will have to write code based on thier assigned rules.

As for the folder :
## 📁 Project Structure

│── SourceCode: for the ".cpp" implementation files

│── Documents: for diagrams, flowcharts, texts,documentation.
│── Testing:for test the files.
│── README.md: message for the group.
│── .gitignore
│── update.bat # auto-update script
