Each member will have to write code based on thier assigned rules.

As for the folder :
## 📁 Project Structure
## Space-Crew/
## 1.SourceCode: for the ".cpp" implementation files.
## 2.Include:for all ".hpp" header files.

## 5.Testing:for test the files.
## 6.README.md: message for the group.
## 7.gitignore: Github system file.
## 8.update.bat # auto-update script.
